O que acontece por trás de um clique?

A tecnologia que conecta o aprendizado.

O Cognita Hub é uma aplicação real. Programação, redes de computadores e computação em nuvem trabalham juntas para apoiar a aprendizagem matemática de crianças com TEA, sempre mediada por pessoas.

Por trás de cada conexão

Do toque na tela ao dado guardado.

Cada clique percorre um caminho: sai do dispositivo, cruza a rede, atravessa a internet e chega à nuvem, onde a identidade é conferida e o dado é guardado. São seis passos, e o Cognita depende de todos.

  1. 01

    Usuário

    Uma pessoa toca em um botão: o responsável, o tutor ou o dispositivo da criança.

    DispositivoNavegador
  2. 02

    Aplicação web

    O Cognita Hub é HTML, CSS e JavaScript empacotados com Vite. O navegador monta a tela e prepara a chamada.

    HTMLCSSJavaScriptVite
  3. 03

    Rede

    A chamada sai do dispositivo pela rede local, por Wi-Fi ou cabo, até o roteador, que a envia para fora.

    EthernetWi-FiNAT
  4. 04

    Internet

    O DNS descobre o endereço do servidor e os roteadores entregam os pacotes IP, salto a salto, até o destino.

    DNSIPRoteamento
  5. 05

    Supabase

    A API recebe a chamada por HTTPS, confere quem está pedindo (Auth) e repassa ao banco de dados.

    HTTPSAuthAPI · RPC
  6. 06

    Banco de dados

    No PostgreSQL, as regras de RLS decidem o que cada pessoa pode ler ou gravar. A resposta faz o caminho de volta.

    PostgreSQLRLS

E a resposta faz o caminho inverso, em geral em frações de segundo.

Um ecossistema

Três mundos, uma solução.

Nenhuma das três áreas funciona sozinha: a interface precisa da rede para chegar à nuvem, e a nuvem só ajuda a criança quando a interface é clara e acolhedora.

HTTP · DNS HTTPS · API

Desenvolvimento Web

As interfaces e a lógica da experiência.

O Cognita Hub é uma aplicação em JavaScript puro (ES Modules), HTML e CSS, empacotada com Vite. Cada tela, do painel do responsável à trilha da criança, é uma entrada própria do projeto.

HTML5CSS3JavaScriptES ModulesVite

Redes de Computadores

Os protocolos e a infraestrutura que possibilitam a comunicação.

Entre o dispositivo e a nuvem existe uma cadeia de redes. O DNS encontra o servidor, o IP endereça e roteia, o TCP garante a entrega e o HTTPS protege a conversa.

DNSIPTCPHTTPS · TLSEthernet

Computação em Nuvem

Os serviços de autenticação, APIs e persistência de dados.

O Supabase concentra o backend: autenticação, APIs sobre o PostgreSQL, funções (RPC) e armazenamento de arquivos. É lá que as regras de acesso vivem.

Supabase AuthPostgreSQLRLSRPCStorageTurnstile

Uma interface clara, uma rede confiável e uma nuvem que protege os dados: é a soma dos três mundos que transforma um clique em aprendizagem.

O CCNA na prática

Um clique, embrulhado em camadas.

Os conceitos de redes que estudamos no SENAI, no CCNA, não ficam só na teoria: cada um aparece, em algum ponto, na viagem de uma requisição do Cognita. O modelo TCP/IP é o mapa dessa viagem.

  • DNS

    Aplicação

    Traduz um nome em endereço IP.

    No CognitaAntes da primeira chamada, o navegador pergunta ao DNS onde está o servidor do projeto.

  • IP

    Internet

    Endereça cada pacote e define a rota até o destino.

    No CognitaCada pacote leva origem e destino. Os roteadores escolhem o próximo salto até chegar à nuvem.

  • TCP

    Transporte

    Entrega confiável e ordenada, com controle de fluxo.

    No CognitaNormalmente, o handshake de três vias abre a conexão antes de a requisição sair.

  • HTTPS

    Aplicação

    HTTP protegido por TLS: confidencialidade e identidade do servidor.

    No CognitaO login e os dados das famílias trafegam cifrados entre o navegador e a API.

  • Ethernet

    Acesso à rede

    Quadros e endereços MAC no enlace local.

    No CognitaNo primeiro salto, o dado viaja em quadros até o roteador: Ethernet no cabo, 802.11 no Wi-Fi.

Aplicação e transporte

O navegador monta o pedido. Antes de enviá-lo, descobre o endereço do serviço (DNS) e, num HTTPS comum, abre uma conexão TCP e negocia o TLS.

DNSTCPTLSHTTPS

O DNS costuma vir do cache: ele não é consultado a cada clique.
